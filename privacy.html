RiccoCall 개인정보처리방침

시행일: 2026년 11월 19일

RiccoCall(이하 "앱")은 자주 연락하는 사람에게 빠르게 전화·문자를 하도록 돕는 Android 앱입니다. 앱은 인터넷 권한이 없어 어떤 정보도 외부로 전송할 수 없으며, 회원가입·광고·사용 통계 수집 도구도 없습니다. 개발자는 사용자의 개인정보를 수집하지 않습니다.

1. 기기에 저장되는 정보

정보저장 위치
사용자가 직접 등록한 사람의 이름과 전화번호, 표시 순서사용자 기기 안의 앱 저장 공간
설정(펼치는 위치, 전화·문자 동작)사용자 기기 안의 앱 저장 공간

이 정보는 개발자나 제3자에게 전송되지 않습니다.

2. 권한 사용

권한사용 목적
연락처 읽기 (READ_CONTACTS)사용자가 연락처에서 사람을 고를 때, 그리고 등록한 번호에 해당하는 연락처 사진을 화면에 보여 줄 때만 사용합니다. 연락처 전체를 저장하거나 복사하지 않습니다.
전화 걸기 (CALL_PHONE)사용자가 등록한 사람을 눌러 전화를 걸 때만 사용합니다. 허용하지 않으면 번호가 입력된 전화 앱을 열어 사용자가 직접 걸도록 합니다.

문자는 기기의 기본 문자 앱을 열어 보내므로 앱이 직접 문자를 보내지 않습니다.

3. 정보의 삭제

  • 등록한 사람은 앱의 목록 편집 화면에서 지울 수 있습니다.
  • 앱을 삭제하면 기기에 저장된 앱 데이터가 모두 삭제됩니다.

4. 아동의 개인정보

앱은 아동을 대상으로 개인정보를 수집하지 않습니다.

5. 변경 및 문의

이 방침이 바뀌면 이 페이지에 게시합니다. 문의는 GitHub Issues에 남겨 주세요.

Summary (English)

RiccoCall has no internet permission, accounts, ads or analytics, and the developer does not collect any personal data. The names and phone numbers the user chooses to add are stored only on the device. Contacts permission is used only to pick a contact and show its photo; the phone permission is used only to place a call when the user asks. Text messages are sent through the device's default messaging app.
